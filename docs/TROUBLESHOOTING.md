# 排障指南

适用版本：0.1.4。先确认使用的是团队服务、本机演示还是 GitHub Pages；公开演示不提供登录、邀请或 Agent 接口。

## 登录与初始化

| 现象 | 检查与处理 |
| --- | --- |
| Cross-site writes are not allowed／不允许跨站写入 | 使用配置的前端地址。`localhost` 和 `127.0.0.1` 是不同 origin；检查 Go 的 `COFLOW_WEB_ORIGIN`、协议和端口，及 Next.js 的 API 转发目标。不要关闭源站校验来绕过错误。 |
| 登录后仍回到登录页 | 检查 Cookie 是否被浏览器接受；本机 HTTP 使用 `COFLOW_SECURE_COOKIES=false`，生产 HTTPS 使用 true。确认代理没有切换域名，且数据库连接正常。 |
| 不显示初始化表单 | 空实例需配置至少 32 位的初始化 token 并打开完整 `/?token=…` 链接。网页读取后会清除参数；刷新后需重新打开私密链接。已初始化的实例应直接登录。 |
| 初始化返回 503／403 | 503 检查服务器 token 配置；403 检查私密链接是否正确。不要把 token 放进工单或公开日志。 |
| 无法加入邀请 | 使用完整链接，核对受邀邮箱／后缀、团队和邀请人。邀请 7 天有效、一次性使用，已撤销／使用／过期需重新邀请。已有账号使用原密码。 |
| 忘记密码 | 当前没有找回密码入口；联系实例维护者处理，不要用邀请重置已有账号。 |

## Agent 与简报

| 现象 | 检查与处理 |
| --- | --- |
| 页面有凭证，Agent 却未配置 | 在正确电脑、当前项目执行安装提示词；检查 Agent 是否能发现 Skill 和明确的项目关联。 |
| 401 | 检查凭证过期、撤销及成员资格；安装当前目标身份的有效凭证。 |
| 403／身份不一致 | 区分 JSON 权限错误与代理拦截页；核对团队、成员和 scope，停止错误身份操作。不要换账号绕过限制。 |
| 返回 HTML 或跳转 | 确认 API 路径、服务地址、反向代理和 CDN 配置；不要向另一站点转发凭证，也不要把登录页当成成功响应。 |
| 连接失败／TLS 错误 | 先无凭证请求 health，检查服务、DNS、网络与证书。远程 Agent 的 `127.0.0.1` 指向它自己；使用可访问的服务地址。不要禁用证书校验。 |
| POST 超时／结果不确定 | 先查询既有简报和 source_id，确认是否已写入，再沿用同一标识重试；不要盲目新建。 |
| 429／5xx | 按 Skill 有限重试并遵守 Retry-After；持续失败则停止并给出可操作提示。 |
| 编辑冲突 | 保存草稿，重新读取最新简报后合并；不要覆盖其他成员的新变化。 |
| 已删除 source_id 返回 409 | 到网页回收站核对并由有权限的人决定是否恢复；不要换来源标识重建。 |
| 分享链接不可用 | 确认登录和当前团队；已删除或其他团队的简报不会通过分享链接暴露。 |
| 重复简报 | 检查是否更换 source_id、成员或团队。新标识表示新工作。 |
| 每日检查没有上报 | 无实质变化时静默跳过是预期行为；同时确认 Agent 自身的调度器已获授权并运行。 |
| 本机保存失败 | 不宣称安装完成；修复用户目录权限或由用户完成配置。服务端已成功上报时，单独修复关联记录，不重复新建。 |

更完整的状态码、响应结构校验和恢复规则见[规范 Skill](../skills/coflow-report/SKILL.md)。

## 语言、日期与个人资料

- 账号菜单直接切换语言；登录后账号偏好优先于浏览器缓存，业务内容不自动翻译。
- 不同成员看到不同日期分组时，检查「个人信息 → 资料 → 展示时区」。支持区域、城市前缀与模糊搜索，选择后自动保存；不修改原始时间戳。
- 昵称按团队保存，头像跨团队沿用。上传使用 PNG／JPEG／WebP（不超过 5MB），网页会裁剪缩小后保存；不支持 SVG 或远程头像 URL。
- 修改密码需要原密码；成功后其他网页登录会话失效，当前会话和 Agent 凭证保留。设备停用时另行撤销凭证。

## 部署与支持

先查看 `/api/v1/health`、容器健康状态、API 日志、数据库连接、磁盘和迁移结果。升级／恢复步骤见[部署指南](DEPLOYMENT.md)，不要通过删卷解决迁移错误。

反馈时提供版本、运行模式、脱敏操作步骤、预期和实际结果。只上传合成数据或脱敏片段，移除 token、Cookie、初始化／邀请链接、数据库连接串、真实成员和私有交付链接。安全问题按 [SECURITY.md](../SECURITY.md) 私下报告。
