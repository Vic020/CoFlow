# CoFlow 基本使用指南

适用版本：0.1.0。CoFlow 是可自托管的团队进展与交付空间，当前未提供公共托管实例。本文所有身份、地址和链接均为示例。

## 1. 启动自己的实例

本地开发需要 Node.js 24、Go 1.25 和 Docker。克隆仓库后：

```sh
npm ci
docker compose up -d db
```

分别在两个终端启动：

```sh
DATABASE_URL='postgres://coflow:coflow_dev@127.0.0.1:5432/coflow?sslmode=disable' npm run dev:api
```

```sh
npm run dev
```

访问 `http://127.0.0.1:3000`。以上数据库密码只适用于本机示例，公网部署使用自己的私密配置。只看示例可用 `npm run dev:demo` 替代团队模式后端；不要同时让两个后端占用 8080 端口。

公网环境按 [部署指南](DEPLOYMENT.md) 配置域名、HTTPS、数据库隔离和备份。远程成员或云端 Agent 不能通过你电脑的 `127.0.0.1` 访问实例。

## 2. 创建团队与邀请成员

1. 首次打开依次填写团队名、个人称呼、邮箱与密码，密码至少 8 位。
2. 左上角团队菜单可切换团队或新建团队，每个团队可使用不同称呼。
3. 在团队设置的“邀请”中输入受邀邮箱，复制一次性邀请链接，自己发送给对应成员。
4. 受邀人使用完整链接加入，已有账号需验证原密码；邀请不是找回密码入口。

邀请目前不自动发邮件。为保护首个管理员，公网空实例先限制访问，初始化后再向团队开放。

## 3. 手动上报与浏览

- 点击顶部“上报”，在手动页签填写标题、说明、项目、领域、状态与交付链接；最多 20 个链接，可提醒多名成员。
- Timeline 展示简报、来源 Agent 与交付链接；按项目、领域、成员、Agent、日期筛选，使用快捷范围和重置。
- 原作者及网页管理员可在详情编辑内容；来源、创建时间和讨论保留。提示简报已有更新时，先保留草稿，再重新打开核对。
- 日报汇总基于原始简报统计交付、阻塞、链接和待办协作，可回到原文讨论。

状态为进展、待反馈、有阻塞、已交付、已解决。领域可填写多个；未知项目或领域进入待整理，团队成员可在设置中审核、改名、设置别名、归档、合并和排序。

## 4. 让 Agent 上报

1. 在“Agent 凭证”创建个人凭证，名称建议包含设备名，例如 `MacBook`；按需选择权限和有效期。
2. 完整凭证只显示一次。复制“配置 Prompt”交给 Agent；它按 Skill 校验目标身份后，保存到 Prompt 指定的用户级文件。
3. 之后使用 Timeline 右侧“复制上报 Prompt”或上报弹窗的 Agent 页签，无需再次复制密钥。

```text
~/.coflow/credentials/<编码后的服务 origin>/<编码后的 team_id>/<编码后的 member_id>.token
```

POSIX 目录权限为 `700`、文件为 `600`，文件只包含 token；已有不同凭证需要确认替换。同一电脑的多个 Agent 可共用此文件，不同电脑建议各自签发凭证。

日常 Prompt 优先读取 `COFLOW_TOKEN`，否则读取指定文件；凭证缺失、失效或身份不匹配时停止。不会扫描项目、其他目录或旧聊天找密钥。浏览器不代替 Agent 写入本机文件，配置失败也不会被视为已保存。

当前正式接入是 Skill 与 HTTP API，CLI／MCP 未来支持。资源位于自己的实例：

- `/agent/coflow-report/SKILL.md`
- `/agent/openapi.yaml`

同一项工作持续沿用 `source_id` 更新原简报；新工作才创建新标识。Agent／Model 是来源参数，真实成员与团队由凭证确定。

## 5. 评论与协作

打开简报详情发表评论并提醒成员，或提出协作请求并选择负责人。负责人可以接手、记录进展、标记阻塞、完成或取消。

“与我相关”包括自己发布、评论、被提及或参与协作的动态；“待我处理”仅包含分配给自己且未完成的协作。“未读”是独立条件。通知可跳转到相关简报，已读状态跨设备保存。

评论和协作请求不会自动授权 Agent 执行工作；由人决定下一步并指示 Agent 更新。

## 6. 常见问题

**页面有凭证，但 Agent 说未配置？** 页面仅展示凭证元数据；确认已执行首次配置 Prompt，且 Agent 在正确电脑读取指定文件。

**出现 401／403？** 检查过期、撤销、团队成员资格和授权范围。不要借用他人凭证或浏览器 Cookie 绕过权限。

**重复上报出现两条？** 检查是否换了 source_id。相同成员、团队和来源标识才会更新原记录。

**删除本机 token 是否等于撤销？** 不等于。设备停用、丢失或疑似泄露时，应到 Agent 凭证页撤销。

**能找回密码或自动发送邀请邮件吗？** 当前尚未提供邮箱验证、找回密码、自动邮件及管理员转让。

**可以上传日志或截图求助吗？** 仅上传脱敏内容和虚拟数据，排除凭证、Cookie、有效邀请链接、真实团队资料。参见 [贡献约定](../CONTRIBUTING.md) 与 [安全说明](../SECURITY.md)。
