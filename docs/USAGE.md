# CoFlow 基本使用指南

记录版本：0.2.2，包含 Todo 与 Timeline 联动。CoFlow 是可自托管的团队进展与交付空间，当前未提供公共托管实例。本文所有身份、地址和链接均为示例。

## 1. 启动自己的实例

本地开发需要 Node.js 24、Go 1.25 和 Docker。克隆仓库后：

```sh
npm ci
docker compose up -d db
```

分别在两个终端启动：

```sh
export COFLOW_BOOTSTRAP_TOKEN="$(openssl rand -hex 32)"
export DATABASE_URL='postgres://coflow:coflow_dev@127.0.0.1:5432/coflow?sslmode=disable'
npm run dev:api
```

```sh
npm run dev
```

首次打开 `http://127.0.0.1:3000/?token=<本机初始化 token>`，其中 token 使用第一个终端中生成的值；后续直接访问首页登录。以上数据库密码只适用于本机示例，公网部署使用自己的私密配置。只看示例可用 `npm run dev:demo` 替代团队模式后端；不要同时让两个后端占用 8080 端口。

公网环境按 [部署指南](DEPLOYMENT.md) 配置域名、HTTPS、数据库隔离和备份。远程成员或云端 Agent 不能通过你电脑的 `127.0.0.1` 访问实例。

## 2. 创建团队与邀请成员

1. 维护者配置至少 32 位的 `COFLOW_BOOTSTRAP_TOKEN`，通过私下提供的 `/?token=<setup-token>` 初始化链接进入，依次填写团队名、个人称呼、邮箱与密码，密码至少 8 位。缺少或错误的初始化 token 无法创建首个管理员。
2. 左上角团队菜单可切换团队或新建团队，每个团队可使用不同称呼。
3. 在团队设置的“邀请”中输入受邀邮箱，复制一次性邀请链接，自己发送给对应成员。
4. 受邀人使用完整链接加入，已有账号需验证原密码；邀请不是找回密码入口。

团队管理员可在“团队设置 → 成员”中直接切换成员／管理员角色，包括自己的角色；至少保留一位管理员。普通成员与 Agent 无权修改角色，变更在后续请求生效。

邀请目前不自动发邮件。为保护首个管理员，公网空实例先限制访问，初始化后再向团队开放。

## 3. 手动上报与浏览

- 点击顶部“上报”，在手动页签填写标题、说明、项目、领域、状态与交付链接；最多 20 个链接，可提醒多名成员。
- Timeline 展示简报、来源 Agent 与交付链接；按项目、领域、成员、Agent、日期筛选，使用快捷范围和重置。
- 原作者及网页管理员可在详情编辑内容；来源、创建时间和讨论保留。提示简报已有更新时，先保留草稿，再重新打开核对。
- 详情可复制当前简报链接和 source_id；链接只向当前团队有权限的已登录成员展示，删除或无权限时提示不可用。
- 作者或团队管理员可将简报移入回收站，从 Timeline 的回收站恢复。评论也可由作者或管理员删除，在详情的“已删除评论”中恢复。删除保留审计记录，不提供永久清空；Agent 不能删除、恢复或访问回收站。
- 日报汇总基于原始简报统计交付、阻塞、链接和待办协作，可回到原文讨论。

状态为进展、待反馈、有阻塞、已交付、已解决。领域可填写多个；未知项目或领域进入待整理，团队成员可在设置中审核、改名、设置别名、归档、合并和排序。

## 4. 让 Agent 上报

1. 在“Agent 凭证”创建个人凭证，名称建议包含设备名，例如 `MacBook`；按需选择权限和有效期。
2. 复制仅展示一次的“安装提示词”，交给当前项目的 Agent。它校验身份，安装用户级 Skill、保存本机凭证并记录项目关联；本次不发布简报。
3. 安装成功后，在同一项目中对 Agent 说“上报 CoFlow”即可。Timeline 的“复制上报指令”和上报弹窗的 Agent 页签仍提供完整指令，适用于尚未发现 Skill 的环境。

```text
~/.coflow/credentials/<编码后的服务 origin>/<编码后的 team_id>/<编码后的 member_id>.token
```

可让 Agent 创建每日检查任务：先确认执行时间和时区，有实质变化才上报，无变化静默跳过；已有相同任务直接复用。安装不会自动创建定时任务，任务中仅记录本机凭证路径，不包含密钥。

POSIX 目录权限为 `700`、文件为 `600`，文件只包含 token；已有不同凭证需要确认替换。同一电脑的多个 Agent 可共用明确关联的文件，但每个 Agent 都需要能发现该 Skill；新电脑需重新安装，建议各自签发凭证。

项目关联保存在 `~/.coflow/projects/<project-key>/binding.json`，其中 `project-key` 是项目规范绝对路径的 SHA-256。仅记录服务、身份、凭证路径、Skill 路径与工作单元的 `source_id`／简报 ID，不保存密钥、正文或聊天记录，不写入项目或 Git。同名目录不会互相覆盖；关联到另一团队前需要确认。不支持跨会话发现 Skill 的 Agent，仍需使用完整上报指令。

日常 Prompt 优先读取 `COFLOW_TOKEN`，否则读取指定文件；凭证缺失、失效或身份不匹配时停止。不会扫描项目、其他目录或旧聊天找密钥。浏览器不代替 Agent 写入本机文件，配置失败也不会被视为已保存。

当前正式接入是 Skill 与 HTTP API，CLI／MCP 未来支持。资源位于自己的实例：

- `/agent/coflow/SKILL.md`
- `/agent/openapi.yaml`

日常复制的上报指令仅指向 Skill、本机凭证和目标身份。失败时 Agent 会按 Skill 说明下一步，例如重新安装凭证、确认服务地址或稍后重试；不会切换身份或创建重复简报。

同一任务沿用稳定任务 ID 与任务 source_id；每次独立进展使用新的简报 source_id，修正同一条简报时复用其 source_id。任务和简报的标识独立。Agent／Model 是来源参数，真实成员与团队由凭证确定。完整协作方案与按工具接入见 [CoFlow 协作指南](COLLABORATION_GUIDE.md)。

## 5. 评论与协作

打开简报详情发表评论并提醒成员，或提出协作请求并选择负责人。负责人可以接手、记录进展、标记阻塞、完成或取消。

“与我相关”包括自己发布、评论、被提及或参与协作的动态；“待我处理”仅包含分配给自己且未完成的协作。“未读”是独立条件。通知可跳转到相关简报，已读状态跨设备保存。

评论和协作请求不会自动授权 Agent 执行工作；由人决定下一步并指示 Agent 更新。

## 6. 个人信息

左下角账号菜单 → 个人信息：

- **资料**：上传或移除头像、修改当前团队昵称和展示时区。头像先在浏览器居中裁剪、缩小，再保存到本实例；头像跨团队沿用，昵称按团队独立。
- **密码**：填写当前密码、新密码和确认密码。修改后其他网页登录会话失效，当前会话保留；Agent 凭证仍需在凭证页单独撤销。

展示时区可输入区域／城市搜索，支持前缀与模糊匹配；选中后自动保存，动态、日报分组和日期随之更新；不会修改团队时区或原始时间戳。

语言仍在账号菜单中直接切换并自动保存；菜单底部显示当前应用版本。演示团队不提供真实账号资料或密码修改。

## 7. 常见问题

**页面有凭证，但 Agent 说未配置？** 页面仅展示凭证元数据；确认已执行安装提示词，且当前 Agent 在正确电脑、项目中能发现 Skill 和项目关联。浏览器无法确认本机安装状态。

**出现 401／403？** 检查过期、撤销、团队成员资格和授权范围。不要借用他人凭证或浏览器 Cookie 绕过权限。

**重复上报出现两条？** 检查是否换了 source_id。相同成员、团队和来源标识才会更新原记录。

**删除本机 token 是否等于撤销？** 不等于。设备停用、丢失或疑似泄露时，应到 Agent 凭证页撤销。

**能找回密码或自动发送邀请邮件吗？** 当前尚未提供邮箱验证、找回密码及自动邮件。

**可以上传日志或截图求助吗？** 仅上传脱敏内容和虚拟数据，排除凭证、Cookie、有效邀请链接、真实团队资料。参见 [贡献约定](../CONTRIBUTING.md) 与 [安全说明](../SECURITY.md)。

## Todo 看板与上报联动（0.2）

进入侧栏 Todo，新建任务并选择负责人、项目、领域、优先级与截止日期。桌面可拖拽任务或列；聚焦任务卡片后可用 Alt + 左／右方向键移动列；键盘与手机也可用移动下拉框、置顶／置底和列菜单。全部／与我相关／待我处理结合分类、负责人和搜索过滤，重置恢复默认视图。

“新建任务”提供手动创建、Agent、Skill 和 API 分类，切换时保留草稿。Agent 分类可编辑并复制含草稿的提示词；Skill 分类接入统一 CoFlow Skill；API 分类提供请求和可写字段示例。“Agent 一键管理”复制看板管理提示词，复制成功直接显示在按钮上。离线演示仍生成完整模板，但要求 Agent 复用已验证的真实项目关联；预览地址和演示身份不会成为 API 目标。粘贴提示词不会自动启动其他 Agent，也不代表任务已执行。

点击任务打开居中详情弹窗，默认阅读标题、属性、描述与交付链接。双击字段或点击末尾铅笔原位编辑，保存后恢复阅读，取消或 Escape 放弃该字段修改；手机直接显示铅笔。有写权限才提供编辑入口。还可评论并提醒成员、查看历史、完成或重新打开。完成表示移入完成列，归档另行操作，归档入口可恢复。网页管理员在列菜单新增／改名／排序／设置默认完成列；归档非空列需要迁移全部任务，至少保留一个未完成列和一个完成列。

任务详情的上报进展预选当前任务与分类，上报弹窗也能搜索并关联其他任务。默认保持任务状态，可明确选择上报后移动到哪一列。冲突时保留草稿并重新读取任务修订，联合写入失败即全部回滚。简报已交付不自动代表任务验收完成。

Timeline 卡片上的任务标签打开 Todo，任务里的关联简报回到 Timeline。简报详情可创建带来源的新任务，编辑简报可关联已有任务。协作请求转为任务后显示由 Todo 跟进，旧协作不再独立维护状态或重复计入待处理。日报将任务完成事件单列展示，与简报交付数分开。

创建人、负责人和网页管理员可维护任务，团队成员可讨论。Agent 凭证页新增只读任务、读取与管理任务、上报／任务／评论权限选项，旧凭证不会自动扩权。通过统一 [CoFlow Skill](../skills/coflow/SKILL.md) 的 [Todo 操作说明](../skills/coflow/references/todos.md) 接入；任务移动不意味着已授权 Agent 执行工作。


### Todo 优先级颜色（0.2.2）

卡片左边框按无优先级／低／中／高显示透明／蓝／黄／红，宽度统一为 3px。颜色辅助扫读，原有优先级文字保留；修改优先级后颜色随之更新，不改变任务阶段或完成状态。
