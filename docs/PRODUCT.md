# CoFlow 产品定义

状态：当前版本为 0.2.1，包含 Todo 与 Timeline 联动。提供自托管团队协作与独立离线演示。功能以当前源码和协议为准，部署与容量按实例分别验收。

## 目标

**让团队看见每一次 Agent 推进。**

每位成员可以同时使用多个 Agent 与 AI Coding 工具。CoFlow 提供一个 AI 交付大厅，汇集进展、成果链接与阻塞，让 Agent 快速推进工作，也让人抓住需要关注和决策的重点。通过邀请加入团队，用评论和协作请求推动后续进展。

## 信息架构

- 左侧：Timeline 默认入口、Todo、Agent 凭证、团队设置；支持收起为图标栏并记住本地选择。
- 内容区左上：团队动态标题，副标题在标题右侧同行，不显示面包屑；搜索与上报合并到紧凑页头，不设独立顶部横条。
- Timeline 上方：全部动态 / 日报汇总展示切换；项目、领域、成员、Agent、日期筛选；全部／与我相关／待我处理快捷范围、独立未读条件及重置。
- 主区域：按日期分组、时间倒序的简报，包含成员、Agent、标题、说明、链接、状态和评论。
- 右侧：需要关注的事项、项目概览、成员入口。手机端收起导航与筛选，关注事项折叠展示。
- 日报、项目、领域、成员是同一 Timeline 的聚合或筛选维度，不是并列主导航页面。

## 简报模型

每条简报归属一个成员，可关联一个项目和多个领域，附多个交付链接。Agent 工具与 Model 是来源字段，不代表独立账号或权限主体。

- 必需：标题；接入方 HTTP／Skill 使用稳定 source_id。
- 可选：正文（Markdown）、项目、领域、Agent、Model、链接、关注成员。
- 状态：progress 进展、review 待反馈、blocked 阻塞、delivered 已交付、resolved 已解决。
- 分类与状态独立。一项交付是否有阻塞未来可拆成独立字段，首版先采用单一当前状态。
- 团队模式先按稳定项目 ID 或规范化名称／别名匹配；名称不明确时留空。Agent 可以提议新项目和新领域，未知名称以待整理状态保存，不自动成为正式分类。
- 一条简报可涉及多个领域。成员可审核、改名、添加别名、归档、恢复或合并；合并同步历史简报，保留原文、原始输入和变更快照。人工纠正的归属不会被 Agent 后续 upsert 覆盖。
- 协作请求关联简报、发起人和负责人，状态为待接手／进行中／有阻塞／已完成／已取消；后续进展按时间留痕。发起人、负责人或网页管理员可更新。
- 一天允许多次简报，也允许一次提交完整日报；日报汇总从原始简报按成员整理，保留出处。未上报显示“暂无上报”。
- 来源唯一键：(团队、成员、source_id)。重复请求更新同一简报，保留创建时间和评论。
- 时间存储使用 UTC；展示与日报按个人展示时区分组，未设置时默认 Asia/Shanghai。

## 已确认的团队行为

邀请制；成员可邀请、创建项目、上报和评论；成员只修改自己的上报，管理员可管理全局。领域由团队统一维护。交付文件仍保留在原工具，通过链接引用。

每条简报支持评论、@成员、未读提醒。Agent 可在同步时读取新反馈，第一版由人决定并指挥后续执行，评论不是自动执行授权。

## 技术栈

Next.js + TypeScript + Tailwind CSS + shadcn/ui + Lucide；Go + Gin；PostgreSQL + sqlc + pgx；REST + OpenAPI；Node.js CLI；Docker Compose。

业务逻辑与身份权限统一在 Go 中。Next.js 只负责前端与同源 API 转发。以本地验收为开发入口，以团队部署为最终目标。实例部署清单、域名、服务器、凭证和备份位置私下维护，不写入公开仓库。

## Todo（0.2）

Todo 的产品核心是多人、多 Agent 共同推进交付的敏捷流程。任务承载目标、责任和交付结果；成员及其 Agent 在各自授权范围内分工、推进、反馈，由人确认验收。看板是现有流程视图，自定义列表示阶段，项目与领域表示分类，不以卡片移动次数代替成果。

当前每个团队共享一套流程，每项任务保留一名负责人对结果负责，其他成员及其 Agent 可在授权范围内参与。Agent 复用所属成员身份和权限，工具名与模型仍是来源信息。任务具备优先级、截止日期、交付链接、讨论、事件历史、归档恢复与排序；当前不提供 Sprint、子任务、依赖或自动多 Agent 调度。

协作原则是 Agent 主动参与闭环：读取相关上下文，在既有授权内推进和更新，向人及时指出协作、决策或验收需求，并在实质变化节点与 CoFlow 同步。持续协作委托不要求每个已授权动作重新确认；单次安装或上报不自动扩展授权。统一 Skill 的本地增强见 [Agent 接入](AGENT_REPORTING.md)，未来模块沿用此原则但不提前声称接口可用。

Todo 与 Timeline 多对多关联。任务上报默认只增加进展，可显式选择同步移动任务，由 Go 在同一事务内处理。交付简报不自动代表验收完成，移动卡片和评论不授予执行授权。协作请求可显式转交给一个 Todo，原讨论保留，后续仅维护任务状态。详细行为与验收见 [0.2 实施计划](TODO_V0.2.md)。
