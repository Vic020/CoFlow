# 0.1 团队试用清单

目标：用两名成员、两个不同 Agent，跑通“上报 → 浏览 → 评论／协作 → 持续更新 → 日报”的真实工作流程。

状态：已于 2026-10-24 完成本机隔离双会话验收；真实异地成员与实际 Agent 工具接入仍待试用。已有自动化测试不替代真实团队验收。当前版本 0.1.0；CLI、MCP 为未来支持，本次使用 Skill 或 HTTP API。

## 准备

- 两名成员分别使用自己的账号、Agent 和个人凭证，例如 A 使用 Codex，B 使用 Claude Code。
- 约定一个试用项目和一到两个领域，使用可分享的交付链接。
- 先确认双方浏览器与 Agent 都能访问同一个 CoFlow 服务地址。`127.0.0.1` 只表示各自机器，不能供异地成员访问同一实例；没有可访问地址时，先在本机分开浏览器会话试走流程，异地网络验收留待部署后进行。
- 各自保存自己的凭证，凭证不放进简报、评论或截图。

## 试用流程

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 1. 加入团队 | A 生成邀请并自行发送给 B；B 完成加入 | 双方看到同一团队，成员归属及各自称呼正确 |
| 2. 绑定 Agent | 各自在 Agent 凭证页创建凭证，按一次性提示完成配置 | Agent 使用对应成员的身份，凭证权限与团队正确 |
| 3. 首次上报 | 两个 Agent 分别为同一项目上报不同工作，至少一条包含两个链接 | Timeline 展示正确成员、Agent、项目、领域与可打开的链接 |
| 4. 重复更新 | A 给 Agent 复制快捷上报 Prompt，让它更新刚才的同一项工作 | 沿用 source_id，原简报更新，不出现重复记录；B 的简报不受影响 |
| 5. 人工编辑 | A 在网页修改自己的简报，新增／移除链接，再次打开核对 | 内容保存，来源不变，修订历史存在；多链接可用 |
| 6. 反馈协作 | B 评论 A 的简报并提醒 A；发起一个有明确负责人的协作请求 | 相关成员收到站内通知，“待我处理”显示对应协作 |
| 7. 推进闭环 | 负责人接手、填写后续进展、完成协作；Agent 按人的指示继续上报 | 状态、讨论与交付证据可追溯，完成后退出待办范围 |
| 8. 分类与筛选 | 按项目、领域、成员、Agent 筛选；试用新分类后在设置整理 | 结果正确，重置有效；分类整理后历史简报同步归并 |
| 9. 日报 | 打开日报汇总，对照当天两人的实际工作 | 简报、交付、阻塞、链接与协作统计正确，可回到原文 |
| 10. 手机与持久化 | 手机查看、评论；刷新页面或重新登录 | 布局可操作，内容保留，已读与未读状态符合实际 |

分类合并及凭证撤销测试请使用专门的试用分类和试用凭证，避免影响正在使用的资料。

## 0.1 收尾标准

- 两名成员能独立完成一次上报和一次反馈／协作闭环。
- 无重复简报、错误身份、数据丢失或越权；出现此类问题先修复再推进新功能。
- 桌面、手机的主要操作可完成，没有阻断使用的问题。
- 未部署公网时，网络性能、HTTPS、真实容量及异地试用继续标记待验收，不能按本机结果宣称通过。
- 汇总反馈并修复阻断问题，再进入 0.2 Todo 开发；实际发版和版本号更新另行确认。

## 本机验收结果（2026-10-24）

- 使用两个不同的本机 localhost 子域隔离 Cookie；Alice／Bob 同时登录同一虚拟团队，未覆盖原工作区登录。
- 两条简报由测试接口模拟 Codex／Claude Code 来源，不代表已运行两个真实 Agent 工具。
- Bob 评论并提醒 Alice、分配协作；Alice 收到两类通知并完成协作，待处理数量恢复为 0。
- Bob 无 Alice 简报的内容编辑入口。Alice 保存新增链接和交付状态后，Bob 刷新可见，原评论与协作记录保留。
- 日报核对：2 名成员、2 条简报、1 项交付、0 项阻塞、3 个链接、0 项待办协作。
- 临时服务已停止，测试 fixture 清理临时数据库 schema，账号、会话与凭证未保留。
- 只保留经过人工检查、内容为虚拟数据的 `docs/design/public-preview.png` 作为公开预览；其他验收截图仅留本机。
