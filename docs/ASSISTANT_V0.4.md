# AI 助手首版与使用手册

版本：应用 0.4.3（0.4.0 首版的兼容更新），Skill 1.4.0。发布与部署实际结果见[验证记录](VERIFICATION.md)。完整 0.4 范围见[路线图](ROADMAP.md)，不能用本首版交付替代完整版本验收。

## 页面与操作

- 点击页面右侧贴边的 **AI 助手**按钮展开对话面板，面板顶部可进入独立助手页。展开、关闭和模块切换保持当前会话，左侧导航也保留独立页入口；桌面面板展开时压缩主内容，手机使用全宽面板。
- 首页只有三个常见任务：**查看项目进度、安排任务时间、整理交付简报**。点击将请求放入输入框，可修改后发送，也可直接输入需求。这些是复用原子工具的请求模板，不是自动运行的定时工作流。
- 项目／领域／成员工作范围和当前选中任务、简报、日期随页面传入；它们是检索线索，不是权限或存在性证明。模型按需查询当前团队的真实对象，查询结果带回原模块链接。
- 全屏助手左侧常驻可搜索的历史列表，选中会话直接继续；左栏上方放新对话、运行任务、任务模板、定时任务与 MCP 连接入口，下方保留历史列表和设置入口。点击管理入口直接在右侧展示列表／表单，点击历史会话返回聊天。窄屏和右侧面板使用历史按钮打开管理列表。
- 对话顶部显示当前团队和配置来源、名称、模型。发送时展示查询状态，可停止；默认逐段显示服务商实际 SSE 正文；可关闭“流式”改为完整回复，不模拟打字。隐藏推理不展示，最终 done 后才保存正文与草稿。Enter 发送，Shift+Enter 换行。
- 创建任务、修改已有任务排期、发布简报都先生成待确认卡片。排期显示原时间与新时间，逐项确认；简报可先编辑并保存草稿，再确认发布。取消不会写业务数据。
- 执行卡片显示真实成功或失败；成功后可回到原模块，当前页面数据同时刷新。批量排期最多八张卡，逐项执行，失败项不掩盖其他项结果，也不声称整批原子提交。
- 历史会话仅当前成员在当前团队可读。切换模型配置开始新对话，配置修订变化需开始新对话，原历史不自动转发到其他服务商；切换团队卸载旧对话并中止在途请求。

## 团队与个人配置

个人配置的账号范围与下述新入口从 0.4.3 提供；旧版部署仍按当时行为运行。

1. **左下角账号菜单 → 个人 AI 设定 → 模型服务**管理账号级个人配置，在本人所有空间可用；助手的个人配置入口也打开这里。**空间设置 → AI 服务**只管理当前空间的团队共用配置，由管理员维护。旧的个人设置 URL 会打开独立的个人 AI 设定弹窗。
2. 选择 DeepSeek、GLM、OpenAI／Codex 或兼容 API；填写名称、API Base URL、账户实际可用的模型 ID 和 API Key。OpenAI 使用 Responses，DeepSeek／GLM 使用 Chat Completions；兼容 API 可选择两种协议。
3. 在表单内先点击**验证**，通过后按钮显示“已验证”并禁用，此时才能**保存配置**。验证发送不含业务上下文的最小模型请求，服务商可能计费；保存复用 10 分钟内有效的服务端验证凭据，不重复调用模型。改服务商、协议、地址、模型或密钥须重新验证；只改名称或默认项保留既有验证。列表只显示验证状态，通过编辑进入表单处理待验证配置。验证失败不保存草稿或密钥，原保存配置保持不变；旧版保存／验证 API 保留兼容，不能伪造新连接已验证。
4. 默认选择：本人为当前团队明确选择的配置优先，否则是已验证的团队默认，再是个人默认；未设默认时取对应来源第一条可用配置。原选择失效时提示重新选择，不静默消费另一方的 Key。
5. 没有可用共用配置也没有个人配置时，对话首页先引导个人配置。个人配置按**账号**隔离，与当前空间无关，其他成员及管理员无法通过 API 查看或使用；共用配置仍仅对本空间成员开放，只有管理员可修改。全局共享的是配置和个人默认项；历史对话、任务、定时任务及每个空间的显式模型选择仍按成员／空间隔离。
6. 使用共用配置的费用由团队 Key 账户承担，使用个人配置的费用由本人账户承担。首版不提供平台免费额度、余额推算、费用统计或团队预算控制；模型调用按成员／团队限为每分钟十次（含验证），每轮最多十二次工具调用、五次模型往返，输出上限 2048 tokens，同时最多三项生成／确认请求，避免耗尽数据库连接。

**模型选择（0.4.1）：** 服务商明确显示为 DeepSeek、智谱／GLM、OpenAI／Codex、兼容 API，选择后带出默认地址和可点选的模型建议。模型输入支持候选列表和自定义 ID。先填写 API Key，再点击“自动获取模型”；编辑既有配置可复用原密钥，但更改服务商或地址后必须重新填写密钥。查询经 Go 执行，不在浏览器直连厂商，不保存查询密钥、不修改模型选择、不标记已验证，也不发起对话生成请求。只有配置维护者可用保存的密钥查询；团队普通成员继续使用既有共用配置，不能在此复用管理员密钥。

**账号范围升级（迁移 015，0.4.3）：** 保留既有个人配置的 ID、修订、验证时间和加密字节，并保留旧加密关联上下文以便继续解密，下一次保存时转为账号上下文。各空间原有配置均保留，不合并密钥；若有多个个人默认项，优先保留最近更新的已验证默认，其余保留为普通配置。账号默认的并发修改由事务锁和唯一索引约束。团队配置不迁移；删除原空间不会级联删除个人配置。升级须备份并保留原加密主密钥；旧程序不支持新的个人配置范围，回退须协调 schema／备份，不能只换旧二进制。

OpenAI、DeepSeek 官方支持 `GET {Base URL}/models`；智谱及兼容服务按相同格式尝试探测，不保证提供列表。返回空列表、不支持或失败时保留模型建议和自定义输入；失败会显示原因，重新点击可重试。服务返回的 ID 不代表支持当前协议或工具调用，获取列表不代替验证；在表单中验证通过后保存。候选列表只保留内存，改变服务商、地址或密钥即失效；请求中修改表单后，旧结果不会覆盖新候选。

内置建议于 2026-11-07 核对官方文档：DeepSeek `deepseek-flash` / `deepseek-v4-pro`，智谱 `glm-5.3`，OpenAI `gpt-5.4` / `gpt-5.4-mini`。它们是可编辑建议，不是账户可用性承诺，也不会自动升级旧配置。来源：[DeepSeek 当前模型](https://api-docs.deepseek.com/)、[DeepSeek 列表接口](https://api-docs.deepseek.com/api/list-models/)、[GLM-5.3](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)、[OpenAI 模型](https://developers.openai.com/api/docs/models/all)、[OpenAI 列表接口](https://developers.openai.com/api/reference/resources/models/methods/list)。

Codex 这里指账户通过 OpenAI API 可调用的相关模型；应用／CLI 登录态、订阅和 CoFlow Agent Token 不能作为本表单的 API Key。首版按协议完成模拟服务契约测试；各厂商真实账户、模型及网络仍需实际验证，不将“协议已实现”表述为“所有模型均已实测”。Claude、Gemini 原生协议等其他服务商适配留待后续。

## 独立联网服务（0.4.3）

个人 AI 设定与空间设置均提供独立“联网服务”，首批支持 Tavily、DeepSeek、Exa、Firecrawl 的搜索和单页抓取。联网密钥与模型密钥分开；可跨模型厂商使用，不再根据 DeepSeek 模型配置决定是否可联网。聊天工具栏默认关闭，主动开启后选择已验证配置；定时任务与离线演示仍不联网。

配置先验证再保存；个人配置跨空间、团队配置仅当前团队共享。保留每轮限量、失败不自动重试、公开 HTTPS 与已知凭证过滤、来源／供应商／请求数记录及 Go 业务确认边界。迁移 016 不自动复制旧模型密钥。供应商依据、计费边界、使用步骤与升级说明见[独立联网服务](WEB_SERVICES.md)。

## 原子能力与联动

| 工具 | 行为 | 业务写入 |
| --- | --- | --- |
| read_workspace | 当前团队元数据、分类及任务列 | 无 |
| find_todos | 查询未归档任务、修订、排期及截止日期，分页 | 无 |
| find_reports | 查询进度与交付记录，分页并返回来源 | 无 |
| read_todo／read_report | 读取单项任务／简报及近期讨论，返回原对象链接 | 无 |
| read_calendar | 按时间范围／时区查询原任务及独立节点排期（起日包含、止日不含，分页携带 revision） | 无 |
| propose_todo | 准备未完成列的新任务 | 确认后创建原 Todo |
| propose_schedule | 准备单个已有任务的新排期 | 确认后通过原 Todo 服务更新 |
| propose_report | 准备关联原任务的简报，支持人工修改草稿 | 确认后写入原 Timeline，状态为进展 |

模型不获得数据库、任意 HTTP、系统命令、通知或其他 Agent 调度工具。外部读取仅通过明确选择、验证并逐项授权的只读 MCP 工具。首版尚不提供助手直接创建独立日历节点、移动／完成任务、删除、分类合并、成员或权限管理；用户可通过对象链接继续在原模块操作。排期与原任务共用修订及操作历史，调整排期不改变 due_date 或完成状态；简报按原规则出现在进度日历。

所有接口仅接受网页登录会话；Agent Token 不因新模块获得额外权限，不修改其 scopes 或安装 Skill。Go 从认证会话确定团队／成员，忽略模型提供的身份；执行时复用各模块已有对象权限与参数校验。会话不接受客户端注入的历史工具结果，真实操作状态从服务端重新读取。

## 服务端与数据

- 迁移 `012_assistant.sql` 增加加密配置、个人会话、待确认动作和配置选择偏好；`013_assistant_workflows.sql` 增加历史管理、版本化模板、定时执行与 MCP 连接；Go 启动时应用。默认不生成任何配置或业务记录。
- 服务端设置独立 `COFLOW_AI_ENCRYPTION_KEY`：使用 `openssl rand -base64 32` 生成，私下保存并通过环境变量传入 Go。生产 Compose 和示例环境文件已提供可选入口，旧部署没有此变量也可继续使用原模块。
- Key 使用 AES-256-GCM，绑定配置 ID、团队和持有人；密文入 PostgreSQL。密钥本身只在服务器环境，不进数据库、浏览器、对话或 Git。必须把数据库备份与加密主密钥分别私密备份；首版没有自动轮换或多密钥解密，直接更换主密钥后旧配置无法读取，需要重新填写服务商 Key。
- 模型服务请求由 Go 发出，只允许公网 HTTPS、443／默认端口，禁止重定向、环境代理和私网地址；连接时重新解析并检查所有 IP，固定拨号地址，防止 DNS 重绑定。自定义配置不能当作任意内网代理。
- 所有助手接口继承 no-store。会话和草稿是私有服务端数据，不进入浏览器持久化；跨页面只在当前已认证的 Provider 内存继续。服务商接收当前请求、有限会话及按需读取的业务上下文，仍受其条款约束。
- 模型读取与生成有 24 秒总超时，单次上游请求至多 22 秒。取消／超时不会执行业务操作；交互请求不自动重试模型计费请求。定时任务按显式授权最多尝试三次，可能重复产生模型费用，但业务产出复用标识。业务确认使用稳定动作 ID 与原模块幂等标识，重试不会重复创建；修订冲突明确失败，需要重新读取后生成草稿。

## 接口摘要

所有路径以 `/api/v1/assistant` 开头，session-only；详见 [OpenAPI](openapi.yaml)。

| 方法与路径 | 用途 |
| --- | --- |
| GET /configs | 当前团队共用与本人配置元数据、默认选择；不返回密钥 |
| POST /configs、PUT /configs/:id | 保存／更新当前归属配置，更新带 expected_revision |
| DELETE /configs/:id | 按修订删除配置，不删除业务成果 |
| POST /configs/:id/verify | 最小模型连接验证 |
| PATCH /preference | 保存本人在当前团队的配置选择 |
| GET /conversations、GET /conversations/:id | 本人当前团队历史搜索、分页与详情 |
| PATCH /conversations/:id | 重命名、归档与软删除恢复，带 expected_revision |
| GET／POST /templates | 内置及个人／团队模板、不可变版本与参数 |
| GET／POST /jobs、GET /jobs/preview、GET /jobs/:id/runs、PATCH /jobs/:id | 定时任务授权、下次运行预览与执行记录 |
| GET／POST /mcp、POST /mcp/:id/verify、POST /mcp/:id/approve | 远程只读连接、验证与逐项授权 |
| POST /chat | 在指定配置的会话内请求模型和工具；request_id 用于同一请求恢复 |
| PATCH /actions/:id | 编辑本人尚未确认的简报标题／正文 |
| POST /actions/:id | confirm 或 cancel，由 Go 执行并回传实际状态 |

公开 Pages 演示使用独立内存预设回复与合成任务／简报，刷新重置；页面不收集真实 Key，不请求真实模型、账号或数据库。普通 Go local-demo 不提供真实 AI 配置；真实助手需要团队模式。

## 一键 AI 操作的运行状态

Context、Todo、Timeline、Calendar 发起的一键提取／整理汇总到“运行任务”，与定时任务分开。可看本次批处理进度、实际保存内容、待复核数量、错误及助手记录，并返回来源页面。切换页面不停止已授权批处理；停止不取消已经进入服务端的请求，继续只处理剩余部分。当前浏览器会话的摘要按账号／空间缓存；刷新后在途状态待确认，不自动重跑、不假定完成。实际长期结果和对话仍以 Go API 及助手历史为准，详见 [Context 进度与边界](CONTEXT.md#查看-ai-操作进度)。

### Context 一键操作输出边界

一键提取／整理每轮输出上限为 8192 tokens，普通对话仍为 2048；Chat Completions 和 Responses 使用各自对应字段。单来源优先生成一份精简主文档，避免重复全文与长引用；一键操作最多八轮模型／十二次工具调用，普通聊天仍最多五轮。输出到达长度上限时明确报错，拒绝执行截断的工具调用，不自动增加预算重试或额外计费。实际模型质量、耗时和厂商兼容性仍需使用者主动验收。

模型配置的“配置名称”为可选备注：未自定义时按“服务商 · 模型”实时生成，清空可恢复自动命名；手动名称及已有配置名称不会随模型切换覆盖。保存时保留最终名称，改名不触发重新验证或模型调用。

一键 Context 操作生成有效提案后直接进入服务端保存，不额外要求模型生成结束语；不得因总结轮次耗尽丢弃已验证提案。保存前仍复查配置与对象修订，部分失败和无结果不得当作已完成。服务端诊断日志只记录轮次、已允许的工具名和 read／prepared／failed 状态，不记录参数、正文、模型回复或密钥。
