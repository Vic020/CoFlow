# 界面多语言

0.1.4 提供英文（`en`，默认）和简体中文（`zh-CN`）。语言改变界面文案、日期、数量和上报 Prompt，不自动翻译简报、评论、成员姓名、项目或领域等业务内容。

## 使用与保存

点击账号菜单中的“语言”展开轻量 Popover，点选语言即切换、收起并自动保存；不使用原生下拉选择框、独立设置弹窗或保存按钮。真实账号通过 Go 的 `/api/v1/auth/preferences` 保存到 PostgreSQL，`/auth/me` 返回 `preferences.locale`；换团队、重新登录或换设备后沿用同一账号偏好。API 只接受当前网页登录会话，不能指定其他用户，Agent 凭证无权读写。保存失败时恢复原语言并在菜单内提示。

登录、初始化和邀请页也提供语言选择。未登录及演示模式仅在浏览器保存 `coflow-locale`，不包含账号或凭证；登录后账号设置优先。初次创建账号时会保存当前界面语言。公开 Pages 使用相同界面框架，语言切换不访问真实服务。

## 文案与格式

- `apps/web/lib/i18n/core.ts`：语言注册、插值、复数和日期格式化。
- `apps/web/lib/i18n/messages/en.json`：英文文案字典。现有中文源文案作为消息 ID；简体中文使用源文案回退，避免两份中文内容漂移。
- `apps/web/components/i18n-provider.tsx`：React Context、浏览器偏好、页面标题与 HTML `lang`。
- `apps/web/components/account-language.tsx`：账号菜单中的即时语言切换。

组件使用 `const { t, date } = useI18n()`，不要把界面文案或格式化日期写死在渲染代码中。带变量的消息使用命名占位符，例如 `t("当前显示 {count} 条动态", { count })`；英文数量可用 `{ one, other }` 两种格式，通过 `Intl.PluralRules` 选择。日期使用 `date(value, options)`，默认使用 Asia/Shanghai，登录后沿用账号的 `display_timezone`。展示时区可在个人信息的资料 Tab 修改并自动保存；日期、时间及日报分组一起更新，接口时间戳不变。日期分组键受展示时区影响，文案语言不改变分组键。

项目／成员名称、正文、用户链接标题等数据直接渲染原文，不传入文案翻译函数。现有服务端通知与错误有固定源文案时，可在字典添加对应模板，变量内容保留原文。未知消息回退原文，不显示 undefined 或空白占位。

## 扩展语言

1. 在语言注册表添加 locale、原生语言名称和对应文案字典。
2. Go 偏好校验与数据库约束同步扩展；增加新迁移，不修改已应用迁移。
3. 补齐文案、变量与数量规则，检查日期、长文本、移动端布局、页面标题和无障碍标签。
4. 更新 OpenAPI 的 locale 枚举，运行资源同步和本地检查。


翻译测试覆盖文案键、英文默认值、插值、复数、日期、未知内容回退与英文 Prompt。隔离 PostgreSQL 集成测试覆盖保存、新会话、其他账号、跨团队及 Agent 权限边界。发布与部署仍由维护者分别明确安排。

## 展示时区实现约定

- `display_timezone` 接受有效 IANA 时区或 UTC；不保存 `Local`、无效字符串或浏览器推测值作为明确选择。
- `/api/v1/auth/preferences` 的 GET／PATCH 使用网页登录会话；PATCH 可只更新 locale 或 display_timezone，未传入字段保留。接口结构以 [OpenAPI](openapi.yaml) 为准。
- 个人资料使用可搜索的时区 Combobox；前缀、城市名和忽略大小写／分隔符的直接匹配优先，再提供有限模糊结果。选中后自动保存，失败恢复原值；Esc 关闭候选，不误关整个资料窗口。
- 对真实时间戳使用用户展示时区。仅日期的分组标签避免二次时区转换；「昨天」等计算按日历日处理，不能简单减去 24 小时而忽略夏令时。
- 语言与展示时区是独立偏好：切换英文不能改变日期分组所属时区；切换时区也不改简报正文、原始时间戳或团队配置。

回归检查同时覆盖英文长文案、中文标签、键盘和手机布局；使用合成账号修改偏好，不能操作真实成员账号进行验收。
