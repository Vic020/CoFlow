# AI 助手工作流：实现状态与使用

更新：2026-11-06（Asia/Shanghai）。以下能力纳入应用 0.4.0 首版；发布与部署实际结果见[验证记录](VERIFICATION.md)。安装／部署不会替真实团队启用定时任务或外部连接。模型真实账户和外部 MCP 服务需要用自己的配置联调；合成协议测试不代表所有服务商均已实测。

## 入口与模块联动

0.4.3 起提供独立[联网服务](WEB_SERVICES.md)：个人 AI 设定与空间设置分别维护对应范围，聊天主动开启后可跨模型厂商组合使用；不自动给定时任务或 Agent 增加联网权限。

保留左侧 AI 助手独立页入口与右侧贴边面板。桌面展开面板压缩主内容，切换模块保持宽度；手机使用全宽面板。全屏助手左栏上方放新对话及任务模板／定时任务／MCP 连接入口，点击直接在右侧管理；下方常驻可搜索的私有会话列表，点击即可返回聊天；右侧面板与窄屏通过“历史”管理会话。“任务与工具”集中管理模板、定时任务和 MCP。个人 AI 配置位于左下角账号菜单的“个人 AI 设定 → 模型服务”，按账号跨空间复用；团队共用配置留在空间设置的 AI 服务。助手入口按配置来源进入对应位置；模板、历史、定时任务及 MCP 管理仍保留空间边界。

Todo、Timeline、Calendar 仍是业务事实来源。助手读取当前团队、项目、领域和成员筛选，使用 Go 原子能力查询；交互写入先准备草稿，由人确认原模块执行，保留修订、操作历史及来源链接。不会因为模板或 MCP 内容获得额外权限。

## 历史记录

- 按当前成员与团队隔离，支持正文／标题搜索、游标分页，按今天／昨天／更早分组。
- 重命名、归档／取消归档、软删除／回收恢复使用修订检查；不提供自动永久清理。归档后先取消归档才能继续；恢复不会执行旧草稿。
- 会话切换在当前登录的 Provider 内存保留输入草稿，生成时禁止切换；不把对话或密钥写入浏览器持久化存储。
- 正文下可展开工具执行记录；草稿从权威动作表回读已确认／取消／失败状态，保留决定时间。模型隐藏推理和原始密钥不展示。
- 保存初次模型配置快照，配置修订变化后需要新对话，不把旧历史转交新的服务；累计显示服务商返回的实际 token 用量；缺少用量时显示未知，不推算账单。当前每个会话最多 20 轮，达到上限需要新对话。

## 有版本的任务模板／Skills

内置进度检查、排期建议、交付简报三个模板。选择模板后填写参数，查看指令及工具范围，再使用指定版本。个人可维护自己的模板；团队模板仅管理员可维护。保存会创建不可变新版本，旧版本仍可用于既有会话／定时任务；不会自动升级。

自定义模板参数使用 `{{project}}` 等占位符，名称为小写字母开头的字母／数字／下划线。模板可限制原子工具，不能扩权、运行脚本、安装依赖或跳过写入确认。外部 Coding Agent 继续使用唯一的 [CoFlow Skill](../skills/coflow/SKILL.md)，平台模板不会拆分或改写该入口，也不改变其版本。

## 定时任务

从“任务与工具 → 定时任务”创建：选择已验证的配置、模板版本、参数、请求、运行时间、IANA 时区及工作日，检查 Go 计算的下一次运行时间与筛选范围，再确认保存。可编辑、暂停／恢复；暂停无需依赖模型配置或解密可用，恢复需重新校验授权。可查看最近 50 次运行记录和结果会话。

默认只读和简报草稿。**自动发布到本团队 Timeline 必须单独勾选授权**；后台不执行 Todo 创建或排期变更。无变化只留下执行记录，不制造重复简报；检测覆盖当前筛选的任务、非定时产出的简报与未来 31 天的排期。排期范围滚动本身可能带来新的计划数据。新一次有实质变化的运行使用新的稳定标识；同一次重试复用标识与动作，不按日报复制 Todo。

Go 服务每 30 秒轮询 PostgreSQL 队列，多实例通过行锁与租约领取。错过的执行合并为一次，最多尝试三次，按分钟平方退避；运行超时后可恢复。夏令时不存在的时刻跳过该日，重复时刻只运行首次。权限基于独立、可撤销的数据库任务授权，不保存 Cookie；每次重新验证成员、固定的配置修订及授权。配置变更／删除或失去成员身份会阻断并暂停，重新保存即重新授权，不静默换 Key。

Calendar 上方显示已启用任务的下一次运行计划，点击进入任务记录；它们不是实际进度，不计入上报数量，也不复制 Calendar 节点。只有实际发布的 Timeline 简报进入进度日历。当前没有邮件、推送或系统通知投递，不把计划称为已送达提醒。

## MCP Client

个人／团队管理员可保存远程公开 HTTPS Streamable HTTP 连接，使用可选的服务商 Bearer Token；凭证独立加密，页面和列表不返回原文。先“验证与授权”，逐项选择只读工具，确认后在连接列表勾选用于对话。清空授权工具即可撤销访问，修改连接会清除授权。

实现初始化、协议协商、JSON／SSE 响应、会话头与有界会话清理，支持 2025-11-25、2025-06-18、2025-03-26。调用前检查归属、连接修订、实际工具定义和参数，清单改变需重新验证授权；最多选择三个连接、启用 30 个工具。仅接受声明只读且非破坏性的工具；服务端声明仍需要用户信任该服务商，不能证明第三方内部实现。

网络复用公开地址／DNS 检查、禁止重定向／代理、超时与取消；工具参数采用受约束 JSON Schema 验证，不支持的约束明确拒绝，不跳过验证。外部描述与结果仅作不可信参考数据，不授予业务写权限。依据 [MCP 官方传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)。

本批范围是远程只读 Client：没有本地 stdio、OAuth 授权流程、外部写工具或 CoFlow 对外 MCP Server。需要 OAuth 的服务先由服务商签发适用 Bearer Token；不支持的授权方式明确无法连接。对外 Server 与外部写入仍是独立评估项，不因 Client 上线自动开放。

## 验证与边界

实现迁移 `013_assistant_workflows.sql`、Go 与浏览器隔离、模板版本／参数、时区边界、队列与租约、幂等发布、MCP 清单授权及离线演示验证。实际检查结果记录在 [VERIFICATION](VERIFICATION.md)。

公开 Pages 只用合成内存数据：历史／模板可体验，定时配置不执行，MCP 不连接外部服务也不保存令牌。真实能力需要团队模式、PostgreSQL、`COFLOW_AI_ENCRYPTION_KEY` 及自己的服务配置。支持 Chat Completions／Responses SSE 逐段正文回复及停止生成，流式文本为临时内容，只有 done 事件后的最终回复与草稿持久化；可手动关闭“流式”使用完整 JSON。中断重试复用原请求，不自动重试计费调用。实现参照 [OpenAI 官方流式指南](https://developers.openai.com/api/docs/guides/streaming-responses)。其他原生模型协议、预算账单、全模块管理、OAuth 与对外 MCP Server 仍未开通。
