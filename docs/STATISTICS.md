# Statistics / 数据统计

Status: local implementation under **Unreleased**; application version stays **0.5.3** until a release is explicitly requested. No new SQL migration, warehouse, schedule or export is introduced.

## Read the numbers

Use **Statistics** in the sidebar. The same project/domain/member filters follow Timeline, Todo, Calendar and Context. Select 7/30 days or a custom range (up to 93 civil days), timezone and searchable Agent/model filters populated from recorded attributions in scope. The UI end date is inclusive; the API `to` is exclusive. Counts are computed by Go from permission-filtered PostgreSQL sources, not generated by a model. Pages uses only an independent synthetic, offline projection.

| Metric | Meaning |
| --- | --- |
| New reports | Undeleted reports created in the selected interval; classification and delivery status are current |
| Currently delivered | Those newly created reports whose current status is delivered; not historical delivery events |
| Delivery links | Distinct normalized HTTP(S) URLs within each selected report, ignoring fragments and host case; detail IDs hash the normalized URL rather than exposing it; not verified deliverables |
| Reporting members | Distinct report authors; the same member may appear in several project/domain groups |
| Open/review/overdue tasks | Current unarchived snapshots, independent of the selected interval; overdue means unfinished with due date before today in the selected timezone |
| Created tasks | Creation timestamps in range; use creation attribution snapshots when present, otherwise current attribution with a coverage warning |
| Completed/reopened tasks | Distinct task IDs with a recorded transition in range, including valid history of archived tasks; uses the event's assignee, project, domains and source attribution |
| Completion duration | The unfinished cycle ending at the first matching completion in range, in elapsed hours; missing starts are excluded and counted separately; not work hours |
| Unscheduled tasks | Current unarchived unfinished tasks with neither schedule nor due date |
| Planned nodes / scheduled tasks | Current unarchived standalone nodes/task plans overlapping the interval; date ranges keep civil-date semantics, timed ranges use instants; deadline-only tasks are points |
| Scheduled completed | Scheduled tasks above that are currently completed; the denominator is the displayed scheduled-task set, not all period creations |
| Collaborations | Current open/handed-to-Todo states and period creations/completions. Repeated done status without a reopen is not a new completion. Transferred collaborations are excluded from open counts. Old completion updates lack attribution snapshots: completion counts are team-wide only, unavailable under project/domain/member filters; historical groups use unassigned attribution |

Select a count to inspect source records. Details show 50 records per page; their revision is bound to identity, source permissions, filters, timezone and data. Changed data returns 409 and requires refresh; the client does not combine pages from different snapshots. Group rows can open the same metric for that group. A multi-domain object can appear in several groups, while the team total deduplicates IDs. Do not add overlapping groups together or combine report/link/task counts as a single “output” number.

## API and AI

`GET /api/v1/statistics?from=2026-11-01&to=2026-11-08&timezone=Asia%2FShanghai`

Optional: `include_sources=true` returns recorded options independent of selected Agent/model. Other filters: `project`, `domain`, `member`, `agent`, `model`, `group_by=project|domain|member|agent|model`, `metric`, `group`, `offset`, `revision`. The reserved group selector `__unassigned__` selects absent attribution. Responses include metric basis/counts, zero-filled daily event trends, group counts, completion duration buckets, capabilities, coverage flags, generated timestamp and optional paginated source references.

The existing reports/todos/calendar read scopes apply separately. An unreadable module is omitted, including its groups and details; statistics never grants a new scope. Current session/team checks remain in Go. The query uses a PostgreSQL repeatable-read, read-only transaction; it never initializes a board, changes catalog data or acknowledges notifications. It projects existing board JSON/history and report/event/collaboration rows; no independent historical state is fabricated. Source rows/tasks are capped at 100,000 and groups at 1,000: excess returns an explicit error instead of partial counts. These are safety bounds, not tested capacity claims. Narrowing dates only reduces period reports; large current snapshots may require project/data-model optimization.

`read_statistics` gives the assistant the same service result. **AI analysis** starts a new conversation using the selected date/timezone/project/domain/member scope. The assistant must state snapshot versus event basis, missing history and source links; it cannot change records through this tool. API keys are never part of the query or returned data. Browser caching reuses the existing 10-second identity/role/team-scoped read cache, with write/session invalidation and manual refresh; there is no new shared server cache. Refresh retains existing content with a fixed progress indicator; first reads use skeletons.

## 中文使用说明

侧栏进入“数据统计”，沿用顶栏项目／领域／成员范围，选择最近 7 天、30 天或自定义日期及时区。页面结束日期包含当天，API 的 `to` 不包含结束日。数字由 Go 查询现有业务记录得出，AI 只读取并解释。

- 点击数字查看来源，按组查看项目、领域、成员、Agent／模型；明细每页 50 条，原数据变化后刷新，避免混用快照。
- “当前”指标与所选期间无关；完成／重开按历史事件去重，归档不抹去已发生的事件。来源删除、恢复与权限变化遵循原模块规则。
- 简报期间指标使用当前分类；旧任务创建缺少快照时标明按当前归属。协作完成缺少分类／负责人快照，只提供团队总数，带项目／领域／成员筛选时不提供该指标。缺少任务周期起点不推算用时。
- 活动量不等于质量、生产率或工时。多领域分组不可直接相加；简报、链接和完成任务分别展示。
- “AI 解读”直接发起新会话查询同一范围；只读，不改业务。浏览器复用 10 秒身份隔离缓存，手动刷新失效；没有新增服务器共享缓存。
- 当前为本地 Unreleased 实现；尚未发布、部署或扩大外部厂商／MCP／Coding Agent 的验收声明。

## Real-provider acceptance / 真实模型验收

On 2026-11-14, one explicitly authorized local DeepSeek conversation successfully called only `read_statistics`, returned three counts matching the API and a statistics source link, without action drafts or changes to source records. The full turn took about 6.479 seconds. Private responses remain local. This verifies one configured model and small synthetic scope, not other providers or production capacity. See [verification](VERIFICATION.md).

2026-11-14，经明确授权，真实 DeepSeek 只读统计会话通过：三项数字与 API 一致，返回来源链接，无操作草稿，业务记录指纹与指标不变。仅覆盖该配置的一次合成项目查询，不代表其他厂商或生产容量已验收。
