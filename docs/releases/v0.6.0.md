# CoFlow 0.6.0 — Data statistics

- Open **Data** to see report and task trends, task completion times, plans, and collaborations. Use shared project, domain, and member filters, choose a date range and time zone, and search recorded Agent and model values.
- Select a count to inspect the original records. The statistics page distinguishes current snapshots from dated events and identifies missing history.
- The assistant uses the same read-only statistics service. Unified CoFlow Skill **1.6.0** adds guidance for scoped queries, metric definitions, and source pagination. See the [statistics guide](../STATISTICS.md).
- Upgrade retains the existing 16 SQL migrations. The self-hosted service uses PostgreSQL and module read permissions. The GitHub Pages demo uses synthetic data and works offline.
- Local validation covered team isolation, calculation and pagination, browser filters and source drill-down, and a PostgreSQL sample of 5,000 tasks. One authorized DeepSeek query matched three API counts for a synthetic project. See the [verification record](../VERIFICATION.md) for scope and deployment results.
