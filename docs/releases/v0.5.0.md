# CoFlow 0.5.0 — Context knowledge and delivery coordination

## Changes

- Context preserves source-backed decisions, rules and project/domain documents. It supports Markdown, nested directories, revision history, review dates, merge/archive actions and permission-checked links to Todo, Timeline, Calendar and other Context entries.
- Knowledge graph and progressive exploration expose actual relationships and directory branches. Filtering, navigation, source details and mobile layouts share the workspace design; relationships are derived from stored links rather than AI guesses.
- One-click AI extraction and organization run in the selected scope, retain sources and reuse existing subjects. Current sources may become active automatically; uncertain or stale evidence remains pending review. Ordinary assistant chat keeps confirmation cards. Directory actions show progress/results and process only their visible documents.
- Todo blockers guard completion across manual, review, report and assistant paths. Expiring, revocable task/project delegations support member-bound Agent collaboration; grantees can discover their mandates, while unrelated members cannot. Neither feature launches external Agents.
- The unified Skill adds Context tools, knowledge-writing guidance and collaboration rules. Global filters and module heading controls are compact and retain stable refresh layouts.

## Upgrade and validation

Application **0.5.0**; unified Skill **1.5.0**. Existing migrations remain **16**; there is no new SQL migration. Context, blockers and delegations extend the existing transactional PostgreSQL board document. Back up before upgrading and preserve the existing encryption master key, private environment and database volumes. Older binaries may discard these new JSON fields on writes; do not roll back by replacing images alone after new data is written.

The Skill version covers its entry and five reference documents. Replace the whole bundle when explicitly updating an installation; retain credentials and project bindings. Existing tokens do not automatically gain `context:read` or `context:write`. Missing scopes must be configured by the owner through the credentials UI.

Local validation includes 86 JavaScript tests, TypeScript, Go race checks, isolated team/demo production builds and disposable PostgreSQL integration tests. Full HTTP integration initially found a grantee-list visibility defect; it was fixed and targeted delegation/revocation/handoff race tests passed. Synthetic browser acceptance covers graph/exploration, document create/edit, module links, missing AI configuration, mobile layouts and 1.2-second delayed refresh without heading shifts. API CI partitions all HTTP tests into three deterministic parallel groups, retaining race checks and production password costs. Exact-source CI and remote deployment evidence are recorded separately in [verification](../VERIFICATION.md).

Real model output quality, external MCP, actual Coding Agent CLI compatibility and large-team capacity remain unverified. Offline Pages uses synthetic data and makes no real model/API calls. This release does not create provider configurations, schedules or external Agent jobs.
