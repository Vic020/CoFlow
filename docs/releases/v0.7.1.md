# CoFlow 0.7.1

- The CLI page includes a copyable one-line installer and links to release archives and reference docs. The installer verifies the archive and configures PATH for Bash, Zsh or Fish. The manually dispatched workflow can publish verified Linux x64 and Apple Silicon macOS archives and checksum files to an existing Release.
- Personal Agent credentials offer separate module read/write selections and an optional permanent lifetime. Report and task read access includes comments on those records. Permanent credentials can be revoked, and access still depends on current membership.
- Self-hosted upgrades apply PostgreSQL migration 024. Back up the database and retain existing application secrets. See the [deployment guide](../DEPLOYMENT.md).

## 中文

- CLI 页面提供可复制的一键安装命令、发布附件和参考文档链接。安装脚本校验归档，并为 Bash、Zsh 或 Fish 配置 PATH。手动发布工作流支持把 Linux x64、Apple Silicon macOS 的归档与校验文件上传到现有 Release。
- 个人 Agent 凭证支持按模块组合读取和写入，并可选择永久有效。评论复用简报或任务的读取权限。永久凭证可以撤销，访问仍受当前成员资格约束。
- 自托管升级应用 PostgreSQL 迁移 024。升级前备份数据库并保留现有密钥。详见[部署指南](../DEPLOYMENT.md)。
