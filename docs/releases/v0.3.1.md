# CoFlow 0.3.1 — Calendar interactions

- Read, comment on and edit original reports in a centered Calendar dialog. Month, week, day-agenda and node links preserve the date, view and shared filters; direct links and browser Back work in place.
- Reuse complete Calendar projections in the existing scoped 10-second browser-memory cache. Retain matching range previews and show a compact right-side loading indicator; whole month cells are clickable. Writes, refreshes and cross-tab changes invalidate cached snapshots. No server cache or persistent business storage is added.
- Double-click empty dates or times to prefill a plan. A one-time tip introduces this gesture. The compact 28px Gantt add row expands a date-selection row; drag or use arrows/Shift/Enter to choose an inclusive date range.
- Drag blank week-grid time blocks to preview and prefill a half-hour-aligned interval. Reverse selection, Escape cancellation and keyboard creation are supported. Time-zone ambiguity requires an explicit choice. Creation still requires Save and never generates a progress report.

Skill remains **1.3.0**. No new API operation, permission scope or database migration; this is a compatible update from 0.3.0. Back up before deployment and pin verified image digests.

Local validation: 57 JavaScript tests, TypeScript, docs/version checks, isolated team and /CoFlow demo webpack builds, synthetic browser creation/comment/navigation and three-second latency checks. Release-commit CI, image publication and both deployments are verified separately in the [verification log](../VERIFICATION.md). Real Agent long-term trials and production capacity benchmarks remain separate.
