# CoFlow 0.1.4

## 删除与恢复

- 作者和团队网页管理员可将简报、评论移至回收站并恢复；保留内容、讨论和操作历史，不提供永久清空入口。
- Timeline 回收站展示自己或有权管理的已删除简报；简报详情可恢复自己或有权管理的已删除评论。
- 已删除简报退出动态、日报、搜索、协作和通知；Agent 无删除／恢复／回收站权限，沿用已删除 source_id 的上报返回 409。

## 分享与界面

- 详情支持复制简报链接和 source_id；链接定位需要登录及当前团队读取权限，不公开内容或授予权限。
- 头像菜单底部显示应用版本。
- 补齐文档索引、Agent 接入、排障、部署升级／回滚、维护规范、Wiki 映射及 Projects 同步清单；CI 增加只读文档检查。

## 升级

先备份数据库和私密配置、保留旧应用镜像。Go 自动执行加法迁移 009，已有账号无需初始化。软删除内容仍在数据库及备份中；旧版本不理解删除标记，回退旧应用可能重新展示已删除内容，回滚前评估并限制访问。

部署、Pages 与 Release 独立安排，详见[部署指南](../DEPLOYMENT.md)和[维护流程](../MAINTENANCE.md)。本版本不改变公开离线演示的数据边界。

## 验证

验证结果与限制记录在[验收记录](../VERIFICATION.md)。真实 Agent 的跨会话安装、调度能力和异地容量仍需分别试用。
