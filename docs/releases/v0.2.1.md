# CoFlow 0.2.1 · Collaboration Docs, Skill 1.1 & faster loading

## Highlights

- **Docs in the platform:** read collaboration principles, tool-specific setup, page instructions and delivery workflows without signing in or waiting for team APIs. Open it from the sidebar or Skill setup. The guide is currently in Simplified Chinese; interface labels support English and Chinese.
- **Skill viewer:** see the bundled version, inspect the entry and three references, copy content or links, and download files. The viewer reads canonical files during the build.
- **CoFlow Skill 1.1.0:** Agents read relevant work and feedback, advance an explicitly delegated assignment, surface collaboration needs and sync meaningful checkpoints. Reports reuse or create tasks for concrete ongoing, confirmed future and completed work, distinguishing delivery from acceptance.
- **Fewer loading round trips:** Todo loads required context only, queries tasks across columns with complete pagination, and fetches columns and tasks in parallel. Timeline loads independent data concurrently.
- **Browser memory cache:** ordinary team context and lists share a 10-second cache, scoped by account, team and role, with in-flight request deduplication. Writes, session changes, unauthorized responses, refocus and cross-tab changes invalidate it. Auth, credentials and item details remain uncached; private APIs retain `no-store`.

## 主要变化

- 平台新增静态 Docs：协作理念、Codex／Claude Code／Cursor／Gemini CLI 接入、页面和工作手册；正文为中文，界面中英切换。
- Skill 展示区提供版本、能力、接入入口及四份规范原文，支持切换、复制与下载，构建时直接取规范源文件。
- Skill 1.1.0 强化主动协作和任务补齐：说清正在做什么，复用或创建真实工作对应任务，区分计划、交付和验收，保留权限及部分成功边界。
- Todo 按需加载、跨列完整分页，与列配置并行；Timeline 独立请求并行。
- 列表使用按身份隔离的 10 秒浏览器内存缓存并合并请求；写入、身份变化、401、重新聚焦及跨标签更新时清理，不写磁盘或 localStorage，不新增服务器共享业务缓存。

## Upgrade / 升级

No database migration is added; migration **010** remains the latest. Go continues to own business identity, permissions and persistence. Existing Agent Tokens retain their scopes.

Update the **whole Skill 1.1.0 bundle** (entry plus all three references), retaining private credentials, project bindings and stable work IDs. Installing the Skill does not broaden permissions, authorize indefinite coordination, create schedules, or launch external Agents. Report-only requests retain their scope.

无新增数据库迁移。升级应用不会自动替换其他工具已安装的 Skill；整套更新时保留私有凭证和项目关联。首次加载或完整刷新仍需会话验证，其他人／Agent 的更新沿用约 30 秒轮询；缓存与并行加载不能消除网络线路延迟。发布源码、构建镜像与部署是分别执行的操作；本次 Release 不代表 Pages 或自用实例已升级。
