# CoFlow 0.2.0 · Todo & Timeline

## Highlights

- A shared Todo board with custom columns, owners, priorities, due dates, delivery links, comments and history. Filter, reorder, complete, reopen, archive and restore tasks on desktop or mobile.
- Centered task details open in reading mode. Double-click a field or use its pencil to edit in place; save or cancel each field independently.
- Link Todo and Timeline in both directions. Reporting can explicitly move linked tasks in the same transaction, with revision checks and idempotent retries. Existing collaboration requests can be handed over to Todo.
- One **CoFlow Skill v1.0.0** covers installation, reporting and Todo through linked references. Existing tokens keep their scopes; task access must be granted explicitly. Assignment does not automatically launch external Agents.
- The offline demo includes six synthetic tasks linked to Timeline reports, isolated from real services and credentials.

## 主要变化

- 新增团队 Todo 看板：自定义列、负责人、分类、优先级、截止日期、交付链接、评论与历史；支持筛选、排序、完成重开、归档恢复及手机操作。
- 任务详情默认居中阅读，双击或点击铅笔逐字段编辑；新建入口整合手动、Agent、Skill 与 API。
- 任务和 Timeline 双向关联，上报可显式移动任务，同事务校验修订与幂等；协作请求可转交 Todo，避免两份进度。
- 统一 CoFlow Skill 1.0.0，复用既有凭证与项目关联；旧 Token 不自动扩权，任务分配不代表已启动 Agent。
- 离线演示补充六条联动示例；路线图新增 0.6 数据统计规划，未将规划当作已提供能力。

## Upgrade / 升级

Migration **010** adds the per-team Todo document, task notifications and collaboration references. Team mode persists to PostgreSQL; the local API demo keeps Todo in process memory, and the offline demo resets on refresh. Do not seed real teams with demo data.

升级前备份并核验数据库，保留原镜像摘要与私密 Compose。Go 自动应用第 10 个迁移；已有团队无需重新初始化。旧凭证不会自动获得 todos:read/write，按需创建具备对应权限的凭证。统一 Skill 更新时替换入口及三份参考文件，保留私有项目关联、凭证及 work_units。

旧应用不理解 Todo 和新的任务通知／协作引用，回退前限制访问并评估兼容性；加法迁移不等于可直接安全回退。不要自动删除新表、回退迁移或覆盖数据库。详见 [deployment and rollback](../DEPLOYMENT.md)。

## Verification / 验证

Local verification covers Go race tests with disposable PostgreSQL schemas, transaction rollback, revisions, idempotency and team boundaries; TypeScript, translations, Agent prompts, offline data boundaries, docs/version checks and isolated production builds. Browser checks cover task lifecycle, inline editing, bidirectional links, keyboard/touch interactions and responsive layout.

验证细节与限制见 [verification record](../VERIFICATION.md)。首版 Todo 使用团队 JSONB 文档与事务锁；未宣称大规模容量或真实 Agent 跨会话调度验收。GitHub CI、镜像构建、Release、Pages 与私有实例分别核对，不以其中一项成功替代另一项。发布附件仅使用 GitHub 源码归档，不包含凭证、数据库或本机验收文件。
