# CoFlow 0.1.3

[GitHub Release](https://github.com/Vic020/CoFlow/releases/tag/v0.1.3) · 发布日期：2026-10-25

## 本次变化

- 默认英文，支持简体中文；账号菜单直接切换语言并自动保存。
- 个人信息提供资料／密码两个 Tab：头像、团队昵称、展示时区和密码修改。时区支持前缀与模糊搜索，动态与日报按个人时区展示。
- 修改密码校验原密码并撤销其他网页会话，保留当前会话与 Agent 凭证。
- 邀请页提示邀请人的团队称呼与受邀邮箱后缀。
- Agent 凭证使用一次性安装提示词：校验身份、安装 Skill、保存本机凭证并关联项目；后续可说「上报 CoFlow」。日常指令不包含密钥。
- Skill 增加每日变化检查建议和失败恢复规则；创建定时任务需先确认，无实质变化不上报。
- 补齐英文文案、响应式布局、协议、隔离测试与使用文档。

## 升级

升级前备份数据库及私密配置，保留旧镜像与 Compose。Go 启动时执行新增迁移 006–008，分别增加语言偏好、头像和展示时区；已有账号无需重新初始化。参见[部署与备份](../DEPLOYMENT.md)。

本次交付源码及 GitHub 自动生成的源码压缩包，不将真实账号、凭证、镜像配置、数据库或私有验收产物作为 Release 附件。发布源码、更新自托管实例和更新 Pages 相互独立，需分别安排。

## 验证与范围

版本一致性、TypeScript、Agent Prompt、多语言／时区、离线演示测试及隔离 PostgreSQL 全量 Go race 测试通过；团队生产构建和离线静态导出通过。浏览器检查使用合成身份，涵盖语言、时区、个人信息布局及一次性安装提示词。

真实 Agent 的跨会话发现、调度工具及异地容量仍需按环境试用。CLI、MCP、Todo、Calendar、AI 助手和 Context 不在本次功能范围内。详细事实与限制见[验证记录](../VERIFICATION.md)，后续计划见[路线图](../ROADMAP.md)。
