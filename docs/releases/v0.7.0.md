# CoFlow 0.7.0

- The CoFlow CLI is now a standalone Rust binary. Use device login, switch between saved spaces, or grant an agent access to a specific project or task. Browser-reviewed actions can be prepared in the terminal and executed in Agent Credentials. The [CLI guide](../CLI_RELEASE.md) covers installation and archive verification.
- Activity brings recent workspace changes and your inbox into one view. Follow a report from Timeline or star projects and teammates to track relevant discussions and updates.
- AI Assistant can share a revocable, read-only conversation snapshot with the current space. Personal settings cover transient model retries, additional system instructions and scoped approvals for selected actions.
- CoFlow Skill **1.7.0** includes a [CLI guide](../../skills/coflow/references/cli.md) and a [command list](../../skills/coflow/references/cli-commands.md) generated from the Rust command registry. Docs and CLI share the same navigation.
- Self-hosted upgrades apply PostgreSQL migrations **017–023**. Back up the database and retain the existing application secrets before upgrading. See the [deployment guide](../DEPLOYMENT.md).

## 中文

- CoFlow CLI 改为独立 Rust 二进制，支持设备登录、多空间切换和项目／任务范围授权。需要网页确认的操作可在终端准备，再到 Agent 凭证核对执行。安装与校验方法见 [CLI 发布指南](../CLI_RELEASE.md)。
- Activity 汇总最近动态和收件箱。可在 Timeline 关注简报，也可星标项目和成员，跟进更新、讨论与回复。
- AI 助手支持生成可撤销的同空间会话快照，并可配置短暂故障重试、追加系统提示词和部分动作的会话或长期授权。
- CoFlow Skill **1.7.0** 提供 [CLI 使用指南](../../skills/coflow/references/cli.md) 和由 Rust 命令定义生成的[完整命令表](../../skills/coflow/references/cli-commands.md)。Docs 与 CLI 共用顶部导航。
- 自托管升级涉及 PostgreSQL 迁移 **017–023**。升级前备份数据库并保留现有密钥。详见[部署指南](../DEPLOYMENT.md)。
