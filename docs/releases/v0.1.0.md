CoFlow｜AI 时代的工作协作方式。

这是首个 GitHub Release，面向自托管团队的早期版本：Agent 上报简报与交付链接，团队通过 Timeline、评论和协作请求持续推进工作。

### 本次包含

- PostgreSQL 账号、邮箱密码登录、团队邀请、多团队与个人称呼。
- 个人 Agent 凭证、权限、有效期和撤销；首次配置保存到本机用户目录，日常 Prompt 指定读取路径。
- Timeline、组合筛选、日报、多人提醒、站内通知与跨设备已读。
- 项目／多领域管理、待整理、别名、归档、合并与排序。
- 网页编辑简报及最多 20 个交付链接，保留来源、讨论与修订历史，并检查过期编辑。
- 协作负责人、处理状态及后续进展；桌面与移动端界面。
- Skill／HTTP API、MIT LICENSE、Docker／Caddy 部署准备及备份步骤。

### 已验证与边界

前端类型、生产构建、版本一致性、Skill 校验及 Agent Prompt 测试通过；Go race 与 PostgreSQL 隔离集成测试通过。本机双浏览器会话验证评论提醒、协作、多链接编辑与日报，Agent 来源为接口模拟。

- 尚未提供公共托管实例；公网性能、2C2G 实际容量及真实异地／Agent 工具验收仍待完成。
- CLI、MCP 标记为未来支持；邮箱验证、找回密码、自动邮件和管理员转让暂未提供。
- 本机 token 文件为明文，需保护用户目录及文件权限。
- 当前分支只保留虚拟公开预览；历史提交曾包含验收截图，本次未改写历史。
