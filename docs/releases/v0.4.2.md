# CoFlow 0.4.2 — Verified configuration, optional web search and stable loading

## Changes

- AI configuration verifies the draft before saving. The verified button is disabled; saving reuses a short-lived, identity/connection-bound proof without a second model call. Connection changes require fresh verification; renaming or changing the default preserves existing verification. Failed drafts do not persist keys. Existing API clients remain compatible.
- DeepSeek official Chat Completions configurations can enable web search/fetch for one turn. Web access defaults off, resets on conversation/configuration changes, and is unavailable for scheduled jobs, proxy providers and the offline demo. Sources and request attempts are recorded separately from token usage. Each turn permits three bounded external requests, reuses successful identical calls, and does not automatically retry failures. Web content is untrusted; module writes still require confirmation.
- Shared loading feedback uses a delayed, fixed-size slot. Assistant management pages no longer insert a spinner row, Timeline refresh retains content, and Todo/initial metadata loading preserves structure. The [UI design standard](../UI_DESIGN.md) defines layout, asynchronous feedback, controls and acceptance requirements.
- Updated synthetic README previews and a resumable manual release runner. Publication, each deployment and reporting remain explicit choices; instance configuration and credentials remain private.

## Upgrade and validation

Application **0.4.2**, unified Skill **1.4.0** (unchanged). No new database migration; migration count remains 14. Back up the database and preserve the existing `COFLOW_AI_ENCRYPTION_KEY` and private environment. Existing configuration records remain usable; editing connection settings follows the new verification flow.

75 JavaScript tests, type/i18n/docs/version checks, isolated team/demo webpack builds, targeted Go race tests and disposable PostgreSQL integration tests passed during implementation. Delayed MCP loading kept heading/description positions unchanged; a 420px viewport had no horizontal overflow. Exact-source main CI, image publication and independent deployment outcomes are recorded separately in [verification](../VERIFICATION.md).

Real provider billing, account/network availability and external MCP/cross-session/capacity acceptance remain separate. No production AI configuration, paid web/model request, schedule or MCP connection is created for release acceptance. GitHub Pages remains a synthetic offline demo with no real backend.
