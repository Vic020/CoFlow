# CoFlow 0.2.2 · Todo priority colors

## Changes / 变化

Todo task cards now show a consistent **3px left border** by priority:

| Priority / 优先级 | Color / 颜色 |
| --- | --- |
| None / 无 | Transparent / 透明 |
| Low / 低 | Blue / 蓝 `#3b82f6` |
| Medium / 中 | Yellow / 黄 `#eab308` |
| High / 高 | Red / 红 `#dc2626` |

Priority text remains visible, and the border width stays fixed when changing priority. This changes presentation only; task status, permissions and data are unchanged.

卡片按无色、蓝、黄、红四档展示优先级，统一宽度避免切换时偏移。保留文字标签，不改变任务流程与完成状态。

## Upgrade / 升级

No database migration is added; migration 010 remains the latest. CoFlow Skill stays at **1.1.0**. Instances upgrading from 0.2.0 also receive [0.2.1](v0.2.1.md): static Docs, the Skill viewer, proactive collaboration rules, browser-memory caching and concurrent loading.

无新增迁移或 Skill 版本变化。从 0.2.0 升级时，也会获得 0.2.1 的 Docs、Skill 1.1.0 和加载优化。整套 Skill 更新需保留既有私有凭证与项目关联，不能只替换入口文件。

Release, image publication and deployments are verified separately. See the [verification record](../VERIFICATION.md) for exact CI, image and deployment results. Production deployment requires a verified server-side backup and retained rollback images; never seed real teams with demo data. Public Pages remains an independent offline demo with synthetic data only.

发版、镜像和两个环境的部署分别记录；部署前备份并核验数据库，保留回滚依据。发布附件只包含公开源码归档。
