# CoFlow 0.1.5

## 成员权限与界面

- 网页管理员可在团队设置中将成员设为管理员或改回普通成员，包括自己的角色；团队始终至少保留一位管理员。
- Go 校验当前团队、会话与角色，并串行处理角色变更；普通成员与 Agent 无权修改角色。权限在后续请求生效。
- 项目、成员、Agent、日期和未读筛选增加选中高亮。

## 镜像交付

- 手动 GitHub Actions 构建已通过 CI 的稳定标签，通用 API／Web 镜像发布至 GHCR，使用摘要部署。
- 不接入生产凭证或团队数据，不自动发布或部署；公开离线演示仍独立维护。

## 升级与验证

无新增数据库迁移。升级前备份数据库与私密配置，保留当前应用摘要作为回滚依据；按[部署指南](../DEPLOYMENT.md)操作。

本地 Go race 与隔离 PostgreSQL 测试覆盖角色升降级、旧会话权限、普通成员与 Agent 拒绝、最后管理员保护及并发降级；类型、翻译、文档与浏览器交互检查通过。云端 CI、镜像构建和运行实例分别验收，不以发布成功替代部署结果。
