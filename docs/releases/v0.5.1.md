# CoFlow 0.5.1 — Visible AI operations and persistent local testing

## Changes

- One-click AI extraction and organization appear in the assistant's **Running tasks** list with scope, item progress, saved/review counts, results and conversation links. The edge entry shows the active count; source buttons link directly to their task.
- Operations continue during client-side navigation. Stop prevents subsequent items after the current request; resume processes remaining items. Scoped session summaries survive refresh as **unconfirmed**, without automatically repeating unknown writes. This is browser execution, not a server queue or cross-device worker.
- A persistent local team environment runs separately from the public offline demo. It includes PostgreSQL, stable encryption keys, local accounts and linked Todo/Timeline/Calendar/Context practice records. Start/stop preserves data; private backups are fully decoded for verification. Optional frontend hot reload uses a separate build directory.
- CI includes operation lifecycle/idempotency/privacy tests and local environment safety tests. User guides explain running-task limits, local setup, backup recovery and the distinction between demo data and real local AI configuration.

## Upgrade and validation

Application **0.5.1**; unified Skill remains **1.5.0**. No new SQL migration; the total remains **16**. Preserve the existing encryption master key, private environment and database volumes. Local sandbox credentials, backups and provider keys stay outside Git and release images. Do not replace an existing local sandbox key or delete its volume when upgrading.

Local acceptance covers 91 JavaScript tests, five Python safety tests, TypeScript/document/version checks, isolated team/demo webpack production builds and synthetic browser tests for navigation, stop/resume, refresh, failures and mobile layouts. Persistent local data and linked records survived a full service restart. Exact-source CI and remote deployment results are recorded separately in [verification](../VERIFICATION.md).

Real model quality and paid provider/MCP/Coding Agent compatibility remain separate acceptance work. Public Pages stays offline and synthetic. This release creates no real model configuration or scheduled jobs.
