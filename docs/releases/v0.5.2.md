# CoFlow 0.5.2 — Reliable Context execution and clearer AI controls

## Changes

- AI extraction and organization show a read-only plan before execution: source count/list, selected configuration, write scope and billing information. Preview/cancel makes no model calls. Confirmation freezes the source list; changes to the selected scope or configuration revision require a new plan.
- Running tasks default to compact, collapsed summaries, including failures. Expand a row to see source-level progress, retained results and available actions. Partially failed batches keep confirmed saves; resume skips processed sources. Refresh restores sanitized summaries and does not restart unknown writes.
- Shared AI buttons keep their action labels and a fixed status slot. Loading switches to stop on hover/focus; touch keeps a visible stop control. Portaled feedback wraps long errors without widening directories, with viewport bounds, keyboard interaction and task links.
- Context proposals enter the save flow without needing an extra model narration round. Context execution has at most eight model rounds and twelve tool calls; ordinary chat keeps five rounds. Context output is bounded to 8192 tokens per call; ordinary chat remains 2048. Truncated tool calls stay rejected; paid requests are not automatically retried. Diagnostic logs contain only allowed tool names, round and state.
- Model configuration names are optional in the form, generated live from provider/model until manually edited. Clearing restores automatic naming; existing names remain intact, and renaming does not invalidate connection verification.
- Network errors distinguish non-public/Fake-IP resolution, DNS failure and timeouts while retaining public-address, TLS and redirect checks. The local sandbox supports a private network Compose override; no machine-specific address or proxy configuration enters public source or production deployment.

## Upgrade and validation

Application **0.5.2**, unified Skill **1.5.0**. No SQL migration is added; the total remains **16**. Preserve existing database volumes, private environment and encryption master key. Local network overrides, model credentials, real responses and screenshots remain outside Git and release images.

Local validation covers 94 JavaScript tests (including operation lifecycle/planning/privacy), six local-environment safety tests, TypeScript, localization, documentation and version checks, Go assistant race tests, and isolated PostgreSQL Context integration tests. The new regression covers proposals delivered in model rounds five and six, actual save/activation and replay without another model call. Team production builds and synthetic browser acceptance cover default collapse, partial failure, plans, stop/resume, long errors, stable directory widths and mobile layout. Exact-source CI and deployment outcomes are recorded separately in [verification](../VERIFICATION.md).

With explicit local testing authorization, the configured DeepSeek model completed a real single-source extraction and a browser-driven two-source batch: **2/2 processed, two returned saves, zero errors**, followed by record readback. This is limited evidence for that local configuration; other providers, external MCP, actual Coding Agent integrations and capacity remain separate acceptance work. Pages stays offline and synthetic. No production model calls or scheduled jobs are created by this release.

## 中文

- AI 提取／整理先显示只读计划：来源清单、工作量、模型配置、写入范围与计费说明。预览和取消不调用模型，确认后固定来源清单。
- 运行任务默认收起，失败也不自动展开；按需查看逐项进度、错误、已保存成果与操作。部分失败保留成功项，刷新不自动重跑未知请求。
- 统一按钮、加载／悬停停止与结果图标；完整提示改用顶层浮层，长错误不再撑宽目录，支持键盘与手机布局。
- 修复有效提案因额外总结轮次不足而回滚的问题；Context 最多八轮模型、十二次工具调用，每轮输出上限 8192 tokens，普通聊天保持原限制。不执行截断工具调用，不自动重试计费请求。
- 配置名称可选并实时生成，手动名称保留；区分 Fake-IP／DNS／超时错误，安全检查不放宽。本机私有网络覆盖不进入公开仓库或生产环境。
- 应用 0.5.2、Skill 1.5.0；仍为 16 个迁移，无新增 SQL。升级保留原数据、私有配置与加密主密钥。
- 本地真实 DeepSeek 单来源及页面两来源提取已验收，后一批 2/2 完成、返回两条保存结果、无错误且回读通过。其他厂商、MCP、Coding Agent 和容量专项未因此完成；精确源码 CI、双环境部署和上报以验证记录为准。
