# CoFlow 0.3.0 — Calendar and shared work scope

Calendar connects actual progress with task plans. Primary Reports, Schedule and Gantt tabs provide month and hourly week views, an upper-right mini month navigator, all-day/deadline rows, timed and overlapping entries, and a current-time line. Reports use original creation instants, not inferred work duration.

- Share project, domain and member filters across Timeline, Todo and Calendar; keep page-specific filters separate.
- Schedule the original Todo and maintain phases, Big Days and business version milestones with source links, revision checks and history. Planning never completes tasks, changes deadlines or authorizes releases.
- Skill **1.3.0** adds the Calendar reference and API guidance. Existing tokens retain their scopes; independent events need calendar:read/write.
- Database migration **011** adds independent calendar events, idempotency and report-range indexing. Back up before upgrade; application rollback does not restore the database.

Validated locally: 49 JavaScript tests, TypeScript, docs/version checks, isolated team and /CoFlow demo webpack builds, Go and Go race against disposable PostgreSQL, desktop and 390px synthetic browser checks. Exact release-commit CI, image publication and deployments are separate verification steps. Real multi-tool Agent trials and production capacity benchmarks remain pending. See [verification](../VERIFICATION.md).

## 中文

Calendar 以“进度／排期／甘特”串联真实简报和计划，支持月历、小时周历、右上角小月历、全天／截止节点、具体时间及重叠排列。三页共用项目／领域／成员筛选。排期复用原 Todo；独立阶段、Big Day 和版本节点保留来源、权限、修订和审计。进度按真实创建时刻显示，不推算工时；改期不完成任务、不触发发版。
